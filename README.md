# thailand-maps

แผนที่จังหวัดของไทยสำหรับทำกราฟ **Region map** ใน Metabase คือแผนที่ที่ระบายสีแต่ละจังหวัดตามตัวเลข เช่น ยอดขายรายจังหวัด

- มีแผนที่ทั้งประเทศ 1 ไฟล์ และแผนที่รายภาค 7 ไฟล์
- ทุกไฟล์แบ่งพื้นที่เป็นรายจังหวัด แผนที่รายภาคคือการตัดมาเฉพาะจังหวัดในภาคนั้น ไม่ได้ระบายสีทั้งภาคเป็นก้อนเดียว
- ข้อมูลที่จะเอามาแสดงต้องมีคอลัมน์ชื่อจังหวัดหรือรหัสจังหวัด
- Metabase มีแผนที่ในตัวแค่ประเทศทั่วโลกกับรัฐของอเมริกา ต้องเพิ่มแผนที่จังหวัดจากที่นี่ก่อนตามข้อ 2

## 2. เพิ่มแผนที่เข้า Metabase

ทำครั้งเดียวต่อแผนที่ และต้องใช้บัญชี Admin

1. กดไอคอนมุมขวาบน → **Admin** (บางเวอร์ชันชื่อ Admin settings) → **Settings** → **Maps**
2. ที่หัวข้อ **Custom maps** กด **Add a map**
3. กรอกตามตารางนี้ แล้วกด **Add map**

| ช่องใน Metabase | ใส่อะไร |
|---|---|
| ชื่อแผนที่ (What do you want to call this map?) | ตั้งเอง เช่น `ไทย - ภาคใต้` ชื่อนี้จะขึ้นให้เลือกตอนทำกราฟ |
| URL for the GeoJSON file | ลิงก์จากข้อ 1 แล้วกด **Load** จะเห็นแผนที่ตัวอย่าง |
| ช่องที่มีคำว่า **region's identifier** | `ADM1_TH` |
| ช่องที่มีคำว่า **region's display name** | `ADM1_TH` |

จะใช้หลายแผนที่ เช่น ทั้งประเทศกับบางภาค ให้กด Add a map แยกทีละแผนที่

**region's identifier** คือค่าที่ Metabase ใช้จับคู่กับข้อมูลของเรา เลือกให้ตรงกับที่ข้อมูลเก็บไว้

| ข้อมูลเก็บจังหวัดแบบนี้ | เลือก |
|---|---|
| ชื่อไทย เช่น `กรุงเทพมหานคร` | `ADM1_TH` |
| ชื่ออังกฤษ เช่น `Bangkok` | `ADM1_EN` |
| รหัสจังหวัด เช่น `TH10` | `ADM1_PCODE` |

**region's display name** คือชื่อที่ขึ้นตอนเอาเมาส์ชี้จังหวัด เลือก `ADM1_TH` เพื่อให้ขึ้นเป็นชื่อไทย

## 3. ทำกราฟแผนที่

1. สร้าง Question ที่สรุปตัวเลขรายจังหวัด เช่น ตั้ง Summarize เป็น Sum of ยอดขาย by คอลัมน์จังหวัด
2. กด **Visualization** แล้วเลือก **Map**
3. กดไอคอนเฟืองเพื่อตั้งค่ากราฟ
   - **Map type**: Region map
   - **Region map**: แผนที่ที่เพิ่มไว้ในข้อ 2
   - **Region field**: คอลัมน์จังหวัด
   - **Metric field**: คอลัมน์ตัวเลขที่ใช้ระบายสี

## 4. จังหวัดเป็นสีเทา ไม่ขึ้นสี

ส่วนใหญ่เกิดจากชื่อจังหวัดในข้อมูลสะกดไม่ตรงกับในแผนที่ ต้องตรงทุกตัวอักษร รวมถึงเว้นวรรค

| ในข้อมูลเขียนแบบนี้ | ต้องเป็น |
|---|---|
| กรุงเทพฯ, กทม. | กรุงเทพมหานคร |
| อยุธยา | พระนครศรีอยุธยา |
| จ.ชลบุรี, จังหวัดชลบุรี | ชลบุรี |
| `ชลบุรี ` (มีเว้นวรรคท้าย) | ชลบุรี |
| `10` | `TH10` |

แก้ที่ข้อมูลต้นทาง หรือสร้าง Custom column ใน Metabase ที่แปลงชื่อให้ตรง เช่น `trim(replace([จังหวัด], "จ.", ""))` แล้วใช้คอลัมน์ใหม่เป็น Region field
